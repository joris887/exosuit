# Hooks Directory

Unified Python hook engine with YAML rule configuration.

- `engine.py` dispatches all hook events to `handlers/` modules
- Rules are defined in `rules/*.yaml` (safety, quality, subagent, intent)
- Session state is stored in `state/session.json`
- Two bash hooks kept: `worktree-bash-fix.sh`, `post-edit-format.sh`

## Adding a new hook handler:
1. Create `handlers/<event>.py` with a `handle(input_data, event, state, load_rules)` function
2. Add the event mapping in `engine.py` HANDLER_MAP
3. Add rules in `rules/<name>.yaml` if needed
4. Register the event in `.claude/settings.json`
5. Document in README.md

See README.md for full hook documentation.
