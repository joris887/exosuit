# Hooks Directory

Deterministic enforcement via shell/Python scripts. All hooks:
- Declare requirements in header comments
- Degrade gracefully (never crash on missing tools)
- Use per-session state in `${TMPDIR}/.claude-hook-state/`

## Adding a new hook:
1. Create script here
2. Register in `.claude/settings.json` (hook event + matcher)
3. Document in README.md
4. Test by triggering the event

See README.md for full hook documentation.
