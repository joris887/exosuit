# Archetype: Viral / Shareable

**Core Question:** "What makes someone share this?"
**Examples:** Wordle, Spend Bill Gates' Money, Spotify Wrapped, BuzzFeed quizzes

## Phase 2: Core Identity Questions

**Q1:** "What does the shareable artifact look like?"
Scaffold: "The screenshot/image/link when shared. Wordle: colored grid. Spotify Wrapped: personalized stats card. Describe the EXACT visual output someone would share."

**Q2:** "What emotion does this trigger?"
Scaffold: "Awe ('whoa'), Humor ('hilarious'), Surprise ('can't believe my result'), Pride ('look what I scored'), Outrage ('this is unbelievable'). Which one?"

**Q3:** "The Dinner Party Test"
"How would someone describe this in one sentence at dinner? If you can't say it in one sentence, simplify."

**Q4:** "The Curiosity Gap Test"
"If you see a friend's result, does that make you want to try it? What specifically about their result makes you curious?"

**Q5:** "The Barrier Test"
"Fastest path from 'heard about this' to experiencing it? How many clicks?"
Scaffold: "Wordle: 0 (just a URL). Spotify: 1 (open app). 'Download app + create account' = high barrier."

**Q6:** "What does sharing say about the sharer?"
Scaffold: "Wordle = 'I'm smart.' Charity = 'I'm generous.' Quiz = 'I'm this personality type.' Yours?"

## Phase 3: Deep Dive

**Design the share moment BEFORE features:**
- "Personalized output format?"
- "Image? Text? Link with preview?"
- "Understandable WITHOUT context?"
- Research: OG tags, social card optimization

**Walk through the experience:**
- "Landing page — first impression? How fast to understand?"
- "Input mechanism — how long before they get results?"
- "Reveal moment — describe frame by frame. Gradual? Sudden? Progressive?"
- "After reveal — share prompt? Try again? Compare with friends?"

## Pre-Mortem Failure Scenarios

- "Nobody shares it because the output isn't visual enough"
- "People start but abandon the input form"
- "It goes viral but the server can't handle load"
- "The humor doesn't land — boring or offensive"
- "A competitor launches something identical next week"
- "Only works on desktop but sharing happens on mobile"
