# Archetype: Personal / Hobby Tool

**Core Question:** "What annoys YOU about how you do this?"
**Examples:** My recipe app, my gym tracker, my reading list, my automation script

## Phase 2: Core Identity Questions

**Q1:** "Walk me through exactly how you do this task today."
Scaffold: "Step by step. What tools do you use? What files/apps/sites? Where does it break down?"

**Q2:** "What's the most annoying part?"
Scaffold: "The specific friction point. Is it data entry? Finding information? Remembering something? Manual repetition?"

**Q3:** "What does 'done' look like for you personally?"
Scaffold: "Not a product vision — YOUR personal definition. When would you say 'this app does what I need'?"

**Q4:** "Would anyone else use this?"
Scaffold: "Both answers are fine. If just you: skip all polish, focus purely on function. If others: we need to think about onboarding and flexibility."

**Q5:** "How often do you do this task?"
Scaffold: "Daily? Weekly? Monthly? Determines how much effort to invest. A daily task justifies more polish than a monthly one."

## Phase 3: Deep Dive

**Current workflow audit:**
Map the existing process: steps, time per step, tools used, pain points. Identify the 80/20 — which 20% of the workflow causes 80% of the friction?

**Minimum viable replacement:**
"If this only did ONE thing, which step of your current workflow would you automate first?"

**Data and persistence:**
"Where does your data currently live? Spreadsheet? Notes app? Your head? How much data are we talking about?"

## Pre-Mortem Failure Scenarios

- "Building the tool takes longer than doing the task manually for the next 5 years"
- "The edge cases in your real workflow make automation harder than expected"
- "You stop using it because the data entry is still tedious"
- "Your workflow changes and the tool doesn't adapt"
