# Archetype: Educational / Explanatory

**Core Question:** "What should someone understand after?"
**Examples:** Kurzgesagt-style explainers, data essays, interactive courses, The Pudding

## Phase 2: Core Identity Questions

**Q1:** "What question does this answer?"
Scaffold: "The Pudding: 'Are there too many Matts in baseball?' Yours? State it as a single question."

**Q2:** "What's the most surprising finding or reveal?"
Scaffold: "The 'aha' moment that makes someone say 'I had no idea.' What's the counterintuitive insight?"

**Q3:** "Who misunderstands this, and what do they get wrong?"
Scaffold: "What's the common misconception this corrects?"

**Q4:** "Why is this better visual/interactive than a written article?"
Scaffold: "Not everything needs interactivity. When does interaction ADD something? Exploration? Personalization? Scale comparison? If a blog post works, build a blog post."

**Q5:** "What data exists? Where does it come from?"
Scaffold: "Government data? Academic research? Your own calculations? Public APIs? This determines feasibility."

## Phase 3: Deep Dive

**Data research:**
- Search data availability: data.gov, Kaggle, relevant APIs
- Search prior art: The Pudding, Flowing Data, NYT Interactive, Observable

**Narrative arc:**
Scaffold: "Which structure fits?
(a) Question → Investigation → Reveal (detective story)
(b) Personal → Data → Universal (start small, zoom out)
(c) Sandbox/explorable (user drives their own discovery)
(d) Scrollytelling (guided linear narrative with visuals)"

**Post-experience question:**
"What should someone DO with this information after? Tell someone? Change behavior? Explore more data? Nothing — just appreciate?"

## Pre-Mortem Failure Scenarios

- "The data doesn't tell a surprising story"
- "Someone already did this, and better"
- "The visualization is confusing rather than clarifying"
- "The data source dries up or changes format"
- "People skim without understanding the core insight"
