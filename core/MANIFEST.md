# Framework File Manifest

This manifest classifies every framework file as either **CORE** (generic, replaceable on upgrade) or **PROJECT** (project-specific, preserved on upgrade). The `/framework-upgrade` skill uses this manifest for targeted upgrades.

## Classification

### CORE -- Replace on Upgrade

These files are generic framework components. On upgrade, they are replaced with the new version. No project-specific content.
