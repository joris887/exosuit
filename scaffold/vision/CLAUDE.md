# Vision Directory

Project vision capture for new projects (Path B in /bootstrap).

## Files
- `BRAINDUMP_PROMPT.md` — template with guided questions covering problem, users, features, technology, and business model
- `README.md` — instructions for the vision capture process

## How It Works
1. User fills out `BRAINDUMP_PROMPT.md` with their project idea (or runs `/bootstrap` interactively)
2. `/bootstrap` (Path B) reads the vision, guides decisions through research-backed options, and generates the project scaffold
3. Discovery outputs are saved here: `idea-capture.md`, `analysis.md`, `discovery.md`, `project-vision.md`
