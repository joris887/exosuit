# Architecture Documentation

System architecture documentation generated by `/bootstrap` and maintained as the project evolves.

## Files
- `ARCHITECTURE.md` — system overview, component diagram, data flow, key decisions

## Conventions
- Max 200 lines — overview only, not exhaustive specification
- Module-level details belong in source-adjacent CLAUDE.md files, not here
- Updated when `/sprint-end` detects architectural changes
- All claims must reference specific source files as evidence
